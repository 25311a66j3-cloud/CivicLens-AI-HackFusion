# CivicLens AI

### Intelligent Civic Issue Verification, Prioritization, Routing & Tracking

**HackFusion 2026 | Software Domain | Team Hit**

> See it. Report it. Resolve it.

## Problem Statement

Civic issues such as potholes, garbage accumulation, water leakage, and broken streetlights are easy to report, but efficiently categorizing, prioritizing, routing, and tracking them remains a challenge.

## Proposed Solution

CivicLens AI is an AI-assisted civic issue management platform that transforms citizen-reported information into structured and actionable data.

Citizens can upload a photo along with the issue location and a short description. The system is designed to identify the issue category, suggest its priority level, recommend the appropriate civic department, and support complaint tracking.

## Key Features

- Civic issue reporting with image, location, and description
- AI-assisted issue classification
- Priority-level suggestion
- Civic department recommendation
- Possible duplicate-report detection
- Unique complaint ID generation
- Complaint status tracking
- Authority dashboard
